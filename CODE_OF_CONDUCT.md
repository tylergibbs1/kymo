# Code of Conduct

kymo follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Expected:** be kind and patient, assume good intent, give feedback on the work rather than the person, and accept correction gracefully.

**Not acceptable:** harassment, insults or personal attacks, sexualized language or imagery, publishing someone's private information, and any conduct that would be inappropriate in a professional setting.

**Enforcement:** report problems privately to the maintainer, [tylergibbs1](https://github.com/tylergibbs1) on GitHub. Responses range from a warning to a permanent ban, as described in the Covenant's enforcement guidelines.
